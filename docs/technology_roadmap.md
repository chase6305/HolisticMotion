# 技术引入评估与优化记录

最新实施进展见[第十轮记录](#第十轮进展限位等价解的有界展开)。

评估日期：2026-09-05。以下优先级来自当前源码、回归测试和本机基准，属于针对
HolisticMotion 的工程判断；候选技术的能力描述链接到官方资料。

## 第三轮已落地

1. **无临时分配的关节距离计算**：`JointSpaceMetric` 为有限关节使用 Eigen
   表达式直接归约，周期关节使用加权最短圆弧距离。近邻与半径搜索比较距离平方，
   边验证复用关节差分。保持公开 API，不新增运行时依赖，搜索复杂度仍是线性扫描。
   C++ 测试开启 Eigen 分配守卫，覆盖权重、周期边界、对称性及整圈等价性。
2. **编译器诊断进入开发流程和 CI**：增加默认关闭的
   `HOLISTICMOTION_ENABLE_SANITIZERS`，在独立 CPU C++ 构建中启用 ASan、UBSan、
   Eigen 断言和可定位的调用栈。本轮检查发现 SE3 轨迹错误地使用 7 维位姿存储长度
   为 6 维切向量创建权重；线性、二阶及五阶 Bezier 段已统一使用切空间自由度。
   这说明仅运行关闭断言的 Release 测试不足以发现矩阵维度错误。
3. **路径后处理保持几何与验证语义**：周期关节回归发现 shortcut 截短旧边后，
   采样网格改变却没有重新验证。现在检查两侧保留片段。插值保留所有原始拐点，
   对新增子段重新验证；检查失败或超时时保留原路径。`interpolation_points` 是
   加密目标数量，返回值可能因这些条件不同于目标，详见[规划说明](zh_CN/planning.md)。
4. **可复现规划基准**：增加默认关闭的 `HOLISTICMOTION_BUILD_BENCHMARKS`，
   输出 CSV，记录耗时、成功状态、迭代数、树节点、检查次数和路径长度。
   运行方法见[开发说明](zh_CN/development.md)。

ASan 提供越界、释放后使用等内存错误检测，UBSan 检测其支持的未定义行为类别；
两者都依赖实际执行覆盖。本配置插桩项目源码，Conan 预编译依赖不带插桩，暂不
支持 Python 扩展或 CUDA 的 sanitizer 构建，不用于发布包。
参见 [ASan 文档](https://clang.llvm.org/docs/AddressSanitizer.html)、
[UBSan 文档](https://clang.llvm.org/docs/UndefinedBehaviorSanitizer.html)。

## 第四轮进展：性质测试与周期距离快速路径

Hypothesis 已作为可选 `test` extra 接入，CI 安装该依赖。默认每组生成 40 个
确定性样例，扩展配置每组生成 300 个。测试包括周期关节整圈等价性、混合关节
FK/IK 与 Jacobian 的基座变换、TOPPRA 单位和时间缩放、RRT* 最佳解随迭代预算
的变化。构造输入时保证路点彼此不同，并限制物理数值范围，避免依靠大量过滤。
运行与重现方法见[开发说明](zh_CN/development.md)。

新增 RRT* 回归复现了最佳目标代价缓存过期的问题：种子 0、`goal_bias=0`、
关闭 shortcut 时，迭代预算从 155 增加到 160，原路径长度从
`1.2968610790` 增大到 `1.3059410917`。重连可能缩短目标节点的祖先路径，
但旧代码仍与较大的缓存代价比较，从而接收更差的目标连接。
现在每轮重连后从目标节点刷新代价。相应用例返回长度为
`1.2908123423` 和 `1.2884380656`；RRT* 与 Informed RRT* 的生成测试均通过。
这些数值为加权关节空间长度，不是米。

周期距离查询增加最短圆弧内的直接计算分支，保留一般插值差分函数。C++ 回归
检查 ±π 邻域、半圈边界、整圈、大数、NaN/无穷以及 10000 个随机角度，与
`std::remainder` 定义的距离平方比较，并在查询期间禁止 Eigen 动态分配。
改动不改变公开函数签名或增加运行时依赖。

本机 Python 3.10.0 触发了标准库的
[dataclass 初始化缺陷](https://github.com/python/cpython/issues/88815)，与本库算法无关。
使用现有 Python 3.10.12 创建临时测试环境并复用已有依赖后，生成测试和全量
回归可以正常执行；项目源码和标准库均没有加入兼容性补丁。

扩展生成测试进一步缩减出 TOPPRA 的三路点失败用例：
`[[0.125, 0, -0.125], [0.25, 0.125, 0.125], [0.375, 0, 0]]`，
速度上限均为 `0.25`，加速度上限均为 `0.5`，`grid_size=20`。
在前向约束投影中，`1-a*x` 的抵消误差被约 `2.4e-15` 的系数放大，导致误报
不可行。修复将数个机器精度的舍入容差施加到无量纲不等式残差，再做除法，
保留小而非零的系数。固定回归同时覆盖空间和时间单位缩放，并使用多项式解析
极值验证整个区间的速度、加速度限制。

## 第五轮进展：CPU 批量 FK 与规划校验

先改进串行 CPU 热点：批量 FK 的每行计算原先调用标量 `GetFK`，生成动态关节
向量与完整中间位姿列表。现改为固定尺寸的位姿累积，每次调用准备一次轴参数，
并合并固定末端与 TCP。准备数据只在单次调用内复用，模型和 TCP 修改无需缓存
失效协议即可在下次调用生效。输出容器仍可复用容量。

核对标量基准时发现 `SO3d(Vector3d)` 是欧拉角构造函数，而旧 FK 将旋转向量
传入该接口。现用轴角旋转处理斜轴，并补全显式 `CONTINUOUS` 节点的 FK 和
Jacobian。对坐标轴平行的单位轴，原结果与修正结果等价，因此性能基准使用此类
关节轴，避免在不同正确性行为上比较耗时；各关节原点和 TCP 仍含旋转与平移。
斜轴正确性由独立矩阵链和 Rodrigues 公式验证，Jacobian 还与差分结果对比。

### 校验语义和回归

- 没有状态校验回调时，采样规划器跳过边细分；有限关节与周期关节均覆盖极小
  `edge_resolution` 和输出插值回归，避免在没有实际校验工作的循环里耗尽时间。
- 路径优化在首个状态及每条边最后一次回调之后检查截止时间。输入校验超时不
  报告可行路径；候选校验超时撤销候选，保留已验证路径。同步回调无法被中断，
  因此预算规定返回语义，不提供硬实时抢占保证。
- 新增 C++ FEP 测试覆盖混合 `REVOLUTE`/`CONTINUOUS` 斜轴、微小角度、TCP
  和模型修改、空批量、越界输入及多余活动末端；Python 回归覆盖 C/F/跨步数组。
- 已有混合关节性质测试扩展为随机斜轴，并加入独立 Rodrigues 位姿参考。

## 第六轮进展：数值 IK 工作区与 TCP 修正

### 正确性与内存行为

FEP 的高精度修正曾新建默认 TCP 的数值求解器，却直接使用带工具的目标位姿。
将工具设为绕 Z 轴旋转 90°、平移 `(0.1, -0.2, 0.05)` 后，固定可达目标在
`SEEDED_NUMERICAL`、`CONFIGURATION`、`ALL_CONFIGURATIONS` 和
`NEAREST_REDUNDANCY` 四种模式均复现失败。现使修正器继承当前 TCP；回归
交替设置工具、单位 TCP 和工具，并确认先触发普通求解残差，再由严格阶段修正。
所有返回解继续满足位置 `1e-5 m`、角度 `1e-5 rad` 的独立检查。

数值 IK 引入仅属于当前调用的 `DampedIKWorkspace`。SVD 分解对象、Jacobian、
投影和步进向量在迭代间复用，世界坐标轴直接写入 Jacobian 计算，避免每轮动态
矩阵分配。保留薄 SVD、原奇异值阈值、阻尼公式、步长和停止条件；初始种子已
收敛时不构造工作区。未引入共享可变缓存或新的运行时依赖。

## 第八轮进展：路径平滑工作区与精确路点校验

### 路点边界正确性

`PathOptimizer` 原先连同终点一起插值后交给校验回调。对于单关节路径
`[[1.0], [0.3]]`，末次计算 `1.0 + (0.3 - 1.0)` 得到
`0.30000000000000004`；回调 `q[0] > 0.3` 接受该值，但返回路径的真实
终点 `0.3` 不满足约束。旧版仍报告路径可行。

现在只对边内部采样插值，并将原始终点交给回调。保持先内部点、后终点的顺序和
回调次数，以及回调后的截止时间检查；候选更新仍复用已验证的相邻端点。新增四组
Python 回归覆盖非法点位于末端或内部路点、粗细两种采样分辨率，旧版全部失败、
新版全部通过。C++ 冒烟测试也覆盖精确终点，诊断配置可检查此路径。

### 调用内工作区

新增内部 `PathGeometryWorkspace`，在单次优化中复用边差分与二阶差分缓冲区。
每个路点只准备一次相邻的至多四条边；回溯试探仅更新两条直接相邻边，两侧外邻边保持
缓存。进入下一路点时重新准备，正反向扫描、接受或拒绝候选都不会使用过期邻边。
优化主循环同时复用梯度、方向、原路点和候选向量。

计算保留原有几何目标、梯度公式、累计顺序和接受条件。工作区属于当前调用，
不增加求解器共享状态、公开 API 或运行时依赖。初始化工作区和输出后，Eigen
分配守卫覆盖首次及后续的路点准备、梯度、局部目标与候选目标计算；这不代表整个
`Optimize()` 零分配，路径、校验采样及可选状态代价仍可能分配。

独立 C++ 测试以完整路径目标变化验证局部目标差，以中心有限差分验证解析梯度，

## 第九轮进展：模型一致性与 FK 边界修复

本轮将完整校验放在模型构造和更新时，保留 FK 运行时的维度和溢出检查。
没有新增依赖或共享可变缓存，普通求解算法和迭代预算保持不变。

修改前的独立 C++ 探针确认：将最后一个固定节点替换为活动节点时，
`SetJointNode()` 返回成功；随后 `SetDOF(100)` 可令自由度变成 100，而 home
向量仍只有一个元素。源码中的 FK、限位和 Jacobian 索引假设这些维度一致。
数值构造器对空列表计算 `size() - 1`，OPW/UR 则无条件设置六维状态。
探针及源码快照保存在 `/tmp/holistic-motion-round9-before/`。

公共行为调整如下：

- 数值构造器拒绝空列表和非法节点，末端必须为 `FIXED` 或兼容的 `UNKNOWN`。
  OPW/UR 至少需要六个有效坐标槽位，后续节点只能固定或 unknown；这些校验
  针对关节元数据，不验证解析几何参数。非法构造抛出 `std::invalid_argument`。
- 数值 `SetDOF()` 保留方法签名，只接受当前维度；其他值抛异常并保留 home、
  权重和过滤器状态。变更模型维度需要重新构造求解器。
- `SetJointNode()` 校验节点数量、字段和坐标覆盖，拒绝活动末端更新；FEP 回归
  相应改为检查拒绝更新后原求解器仍可用。SRS 兼容性检查也要求固定/unknown 末端。
- 硬件限位更新与用户限位更新采用相同的交集检查。C++ TCP 和用户坐标系更新
  要求有限系数及单位四元数；非法更新均保留原配置。
- 单固定节点的零自由度数值模型返回 `6 x 0` Jacobian；IK 只在目标位姿已经
  满足容差时返回一个空关节向量，其他目标直接失败。`IkRtn::PushBack()` 接受
  空配置，仍检查后续配置维度一致；去重和限位筛选保留这个唯一配置。

新增 `kinematic_model_smoke` 使用合成节点检查构造失败、拒绝更新后状态保留、
零自由度求解，以及子类注入的空模型、自由度不符、活动末端和空 FK 输出。
运行时检查防止这些已覆盖异常状态访问不存在的关节或位姿；不承诺任意自定义
子类破坏所有 protected 字段后仍可安全使用全部 API。

## 第十轮进展：限位等价解的有界展开

本轮集中修复 `IkRtn::GetLimitsIK()`。旧实现对越界关节反复加减 `2π`；当输入
为 `1e20` 时，double 的间距已经大于单次减量，值不再变化，循环无法结束。
独立 C++ 探针运行一秒后仍未完成，由测试进程超时终止。旧版对于 `[0, 2π]`
闭区间中的零角度只返回一个解，漏掉另一端点；四种等价种子的 Python 回归全部
失败。旧实现、探针和数值 IK 二进制位于 `/tmp/holistic-motion-round10-before/`，
端点失败日志为 `/tmp/holistic-motion-round10-endpoints-before.log`。

现在直接计算可行整数圈数区间，使用闭区间检查保留限位两端。种子已在限位内时
保留原始值和原有输出顺序。越界种子先取余，极大值若损失旋转相位，则使用
`atan2(sin(q), cos(q))`；最终等价角必须保留原始正弦、余弦，误差均不超过
`1e-10`。无法精确表示的整数圈数范围失败返回，避免生成角度相位不可靠的解。
移动、固定及兼容的 unknown 坐标不进行角度展开。

多关节笛卡尔积用混合进制索引迭代生成，替代递归函数和中间 `vector<vector<double>>`
配置集合；单关节候选、索引和关节缓冲区在当前筛选调用内复用。默认最多生成
**65536** 个配置，C++ 新增 `GetLimitsIK(nodes, max_solutions)` 重载，允许显式
选择 **1 至 INT_MAX** 的上限。预算按所有输入解展开后的配置计数，位于后续去重
之前；相乘前检查剩余容量，超限时不交付部分结果，清空解列表、计数和成功状态。
数值 `solve_all()` 沿用默认上限，解析求解器的最近分支路径仍使用
`WrapToLimitsNear()`。很宽的多圈模型现在可能因预算返回失败，这是明确的 API
行为收紧，不等同于几何目标不可达。

新增 `ik_limit_smoke` 覆盖 ±`1e20`/±`1e100` 输入、闭区间端点、普通输入的
独立有限圈数枚举、组合顺序、精确预算/超预算、巨大限位、非周期坐标、非法限位
和零自由度。CTest 配置十秒超时。六个 Python 回归覆盖端点集合及极大种子的
FK 回代。新增可选 `ik_limit_benchmark` 基准测量 1/7/14 关节的单解和
2/128/16384 个等价配置展开，不依赖外部模型或额外基准库。


普通单解增加独立快速路径：当种子已经在限位内且与两侧边界的距离均不足一圈，
直接保留该配置，跳过圈数除法和候选/索引工作区分配。只有需要展开时才创建这些
缓冲区，并按已检查的组合数量预留输出容量；空解集直接失败返回。回归交替输入
单解、八个等价解、单解，检查两条路径共享同一预算。
