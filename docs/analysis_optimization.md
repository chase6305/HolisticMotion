**已落实的修改**

| 问题 | 复现或源码依据 | 修改与验证 |
| --- | --- | --- |
| 数值 IK 的薄 SVD 维度错误 | `U`、`V` 只有 `min(6, dof)` 列，但原先用 `dof × 6` 的逆奇异值矩阵参与相乘。1 自由度回归在启用 Eigen 断言时中止，提示 `invalid matrix product`；Release 可能掩盖问题 | 改为先将误差投影到奇异向量空间，再逐元素应用奇异值增益，最后乘 `V`。同时省去 U/V 拷贝和显式伪逆矩阵。覆盖 1、3、6、7 自由度的实际迭代 |
| 移动关节被按角度展开 | 位置范围 `[-10, 10]`、目标 `0.5` 的移动关节返回 `0.5`、`-5.783...`、`6.783...` 三个解，后两者不满足目标 FK | `GetLimitsIK` 和 `WrapToLimitsNear` 对移动关节直接检查位置范围；只保留原位置。增加有效解和越界解回归 |
| 连续关节被误读为零范围 | `continuous` 关节带 `<limit velocity="2" effort="3"/>` 时，未声明的上下界被读取为零 | 延续库内 `[-π, π]` 的单圈数值表示，忽略连续关节的 URDF 位置上下界，保留速度/力矩限制；默认链与显式子链共用转换结果 |
| TOPPRA 样条构造使用稠密求解 | 自然三次样条的方程实际是三对角系统，原实现分配 `N × N` 矩阵并调用通用求解 | 改用三对角消元，固定自由度下时间和存储随路点数线性增长；合并网格上的位置和导数查询。验证插值、自然边界、C2 连续性及双路点退化为直线 |
| CTest 清单未更新 | `enable_testing()` 位于函数作用域；重新配置后，已有构建仍保留旧 `CTestTestfile.cmake`，新增测试没有进入清单 | 将 `enable_testing()` 移到顶层目录作用域；从全新目录确认注册四个核心测试；脚本增加 `--no-tests=error` |

**第二轮：重定时语义与数值 IK**

继续优化时，先复现首轮留下的非零边界速度问题，再补充跨模块回归。已完成：

| 修改 | 依据与结果 |
| --- | --- |
| TOPPRA 传播完整可控区间 | 原实现仅保存速度上界，将非零终点速度当作可达范围的上限，最后强行覆盖终点值。现在从精确的终点速度平方出发，反向传播上下界，再正向选择区间内可达的最大值。加速度不足以达到终点速度的请求会明确失败 |
| 在重定时中约束整个区间 | 使用每段路径一阶导数的解析极值限制速度，并约束二次加速度多项式的 Bernstein 系数。移除改变起止速度的全局时间缩放，原先请求 `0.1` 返回约 `0.081876` 的用例现在保留 `0.1` |
| 替换每段 60 次二分探测 | 将区间约束写为相邻速度平方的线性不等式，通过消元直接投影可达范围。此阶段计算量为 `O(N d²)`，持久存储为 `O(N d)`，其中 `N` 为网格区间数、`d` 为自由度 |
| 完善轨迹快照 | 速度与加速度上限现在拥有独立数据，修改调用方的 NumPy 数组不会改变轨迹。`ToppraResult` 新增位移与平均路径速度、时间间隔的一致性检查 |
| 修正几何 Jacobian 对应的 IK 误差 | 位置误差改为世界坐标系下的目标位置减当前位置，旋转误差为目标旋转乘当前旋转的逆。此前 10 米末端偏移、0.001 弧度目标变化可在实际位置仍差 1 厘米时报告收敛；修复后满足 `5e-4` 米的位置阈值。测试还覆盖平移后的机器人基座 |
| 保持 SRS 配置语义 | 修正数值 IK 后，原来没有收敛的数值回退可能收敛到臂角不符的解。对于可构建解析模型的链，现在拒绝被解析配置检查淘汰的分支，并在枚举配置时保留 seed 指定的臂角。非解析模型保留原有数值路径 |
| 补齐文档生成输入 | 严格文档构建发现 `PathOptimizer` 被 API 页面引用，但未列入 Doxygen 输入。补齐后，中英文 Sphinx 构建均通过 `-W` 检查 |

区间速度上限和 Bernstein 加速度约束是连续约束的保守充分条件。
可行结果保持指定的起止路径速度；保守网格判定不可行时抛出异常，增加网格密度
可以减少保守程度。这里不宣称连续问题的全局时间最优。公开函数签名保持不变，
但生成的速度曲线和时长可能变化；不一致的手工 `ToppraResult` 快照现在会被拒绝。

## 第十二轮：轨迹查询与样条边界优化（2026-09-08）

本轮继续检查规划与轨迹核心，落实具有独立复现的样条边界修复及轨迹查询优化。
公共函数签名和依赖保持不变，上一轮几何优化保留。

- `PSpline` 原先按整条样条总时长设置节点吸附容差。两个 0.001 秒短段后
  追加一个 `1e15` 秒长段，查询第一段中点会错误地落到下一段。现改用节点

- `GetState` 共用一次时间样条定位和一次路径段定位，取消位置及三阶导数

## 第十五轮：约束采样数值边界修复（2026-09-08）

本轮处理约束报告及构造时限位检查的采样运算，没有新增公共接口或依赖。

- 约束报告原先计算 `duration * sample / (samples - 1)`。总时长仍为有限
  数时，中间乘法可能先溢出，导致内部状态查询抛出“时间必须有限”的异常。
  现在先计算 `[0, 1]` 内的比例，再乘时长；构造时的分段限位采样采用同样

- 构造时的采样数量原先依赖 `duration / 2000` 得到的目标步长。当正时长
  为极小非正规数时，该步长可能下溢为零，使后续比值非有限并进入整数转换。
  现在先用分段长度除以总时长，再乘目标区间数，保持计数计算有界。
- 节点左侧采样原先用整条轨迹时长估算浮点偏移。一个无关的长尾段可能让
  采样位置退到前段中部，将正常的速度、加速度变化误认为节点跳变。现在
  两处检查共用局部节点时间戳及前一区间长度计算偏移，保留越过样条吸附
  容差的处理。

## 梯形轨迹优化：将无法计时的变速段合并到相邻匀速段（2026-09-14）

## Bezier 长度求解优化：避免近线性方程相消（2026-09-14）

五次 Bezier 的长度方程使用普通二次求根公式。当二次项系数接近零、但
仍高于原有 `Small` 阈值时，`-b + sqrt(delta)` 相消导致正根精度下降。

失败：模长 `1.1428549107121058`、尺度 `2^-10` 时误差约 `3.73e-11`。

`c/q` 得到两根，避免相近数相减。保留较大根选择、近线性分支阈值及
无效长度拒绝规则；双零根单独处理，避免除零。公共签名、依赖和控制点

  省去两个动态点 Jacobian。过滤查询仅为实际返回的配对构造中心和法向量。

## 球体碰撞查询继续优化（2026-09-22）

将普通尺度碰撞查询的范围检查移到配对循环之外。构造模型时记录固定半径的
最小值和最大值，每次查询结合安全间距判断所有配对阈值的平方是否处于正常
浮点范围；满足条件时使用无逐配对范围分支的平方距离循环，否则保留原来的
扩展精度保护。上下界覆盖所有球，因此切换、清空和重置碰撞组无需更新缓存。
