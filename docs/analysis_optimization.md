**已落实的修改**

| 问题 | 复现或源码依据 | 修改与验证 |
| --- | --- | --- |
| 数值 IK 的薄 SVD 维度错误 | `U`、`V` 只有 `min(6, dof)` 列，但原先用 `dof × 6` 的逆奇异值矩阵参与相乘。1 自由度回归在启用 Eigen 断言时中止，提示 `invalid matrix product`；Release 可能掩盖问题 | 改为先将误差投影到奇异向量空间，再逐元素应用奇异值增益，最后乘 `V`。同时省去 U/V 拷贝和显式伪逆矩阵。覆盖 1、3、6、7 自由度的实际迭代 |
| 移动关节被按角度展开 | 位置范围 `[-10, 10]`、目标 `0.5` 的移动关节返回 `0.5`、`-5.783...`、`6.783...` 三个解，后两者不满足目标 FK | `GetLimitsIK` 和 `WrapToLimitsNear` 对移动关节直接检查位置范围；只保留原位置。增加有效解和越界解回归 |
| 连续关节被误读为零范围 | `continuous` 关节带 `<limit velocity="2" effort="3"/>` 时，未声明的上下界被读取为零 | 延续库内 `[-π, π]` 的单圈数值表示，忽略连续关节的 URDF 位置上下界，保留速度/力矩限制；默认链与显式子链共用转换结果 |
| TOPPRA 样条构造使用稠密求解 | 自然三次样条的方程实际是三对角系统，原实现分配 `N × N` 矩阵并调用通用求解 | 改用三对角消元，固定自由度下时间和存储随路点数线性增长；合并网格上的位置和导数查询。验证插值、自然边界、C2 连续性及双路点退化为直线 |
| CTest 清单未更新 | `enable_testing()` 位于函数作用域；重新配置后，已有构建仍保留旧 `CTestTestfile.cmake`，新增测试没有进入清单 | 将 `enable_testing()` 移到顶层目录作用域；从全新目录确认注册四个核心测试；脚本增加 `--no-tests=error` |
| Python 解释器选择不一致 | 脚本中的 `PYTHON_EXECUTABLE` 用于测试，却未传入 CMake；缓存中可能保留另一环境的 Python | 显式向 CMake 传递解析后的 `Python3_EXECUTABLE`，使扩展构建和测试使用同一解释器 |

**第二轮：重定时语义与数值 IK**

继续优化时，先复现首轮留下的非零边界速度问题，再补充跨模块回归。已完成：

| 修改 | 依据与结果 |
| --- | --- |
| TOPPRA 传播完整可控区间 | 原实现仅保存速度上界，将非零终点速度当作可达范围的上限，最后强行覆盖终点值。现在从精确的终点速度平方出发，反向传播上下界，再正向选择区间内可达的最大值。加速度不足以达到终点速度的请求会明确失败 |
| 在重定时中约束整个区间 | 使用每段路径一阶导数的解析极值限制速度，并约束二次加速度多项式的 Bernstein 系数。移除改变起止速度的全局时间缩放，原先请求 `0.1` 返回约 `0.081876` 的用例现在保留 `0.1` |
| 替换每段 60 次二分探测 | 将区间约束写为相邻速度平方的线性不等式，通过消元直接投影可达范围。此阶段计算量为 `O(N d²)`，持久存储为 `O(N d)`，其中 `N` 为网格区间数、`d` 为自由度 |
| 完善轨迹快照 | 速度与加速度上限现在拥有独立数据，修改调用方的 NumPy 数组不会改变轨迹。`ToppraResult` 新增位移与平均路径速度、时间间隔的一致性检查 |
| 修正几何 Jacobian 对应的 IK 误差 | 位置误差改为世界坐标系下的目标位置减当前位置，旋转误差为目标旋转乘当前旋转的逆。此前 10 米末端偏移、0.001 弧度目标变化可在实际位置仍差 1 厘米时报告收敛；修复后满足 `5e-4` 米的位置阈值。测试还覆盖平移后的机器人基座 |
| 保持 SRS 配置语义 | 修正数值 IK 后，原来没有收敛的数值回退可能收敛到臂角不符的解。对于可构建解析模型的链，现在拒绝被解析配置检查淘汰的分支，并在枚举配置时保留 seed 指定的臂角。非解析模型保留原有数值路径 |
| 补齐文档生成输入 | 严格文档构建发现 `PathOptimizer` 被 API 页面引用，但未列入 Doxygen 输入。补齐后，中英文 Sphinx 构建均通过 `-W` 检查 |

区间速度上限和 Bernstein 加速度约束是连续约束的保守充分条件。
可行结果保持指定的起止路径速度；保守网格判定不可行时抛出异常，增加网格密度
可以减少保守程度。这里不宣称连续问题的全局时间最优。公开函数签名保持不变，
但生成的速度曲线和时长可能变化；不一致的手工 `ToppraResult` 快照现在会被拒绝。

## 第五轮：批量运动学与校验截止时间

  和模型更新。

  分离标量旋转修正后，批量循环本身贡献 **1.26–1.36 倍**加速。
  1024 行从约 **631 µs 降至 405 µs**；不含 Python 转换和 GPU 传输。
- 采样规划器未配置校验回调时跳过边细分，极小分辨率不再导致无意义超时。
  路径优化器在最后一次校验回调后也检查截止时间；输入校验超时返回空路径，
  候选校验超时则保留先前验证的路径，避免提交超时后才完成校验的候选。

验证结果：Python **258 通过、10 跳过**；扩展性质测试 **1500 例通过**。

## 第六轮：数值 IK 工作区与工具坐标系

- 修复 FEP 高精度修正遗漏 TCP 的问题。相同关节目标在设置旋转和平移工具变换后，
  原先四种求解模式均失败；现在修正阶段继承当前 TCP，全部通过严格位姿回归。
- 数值 IK 在单次调用内复用薄 SVD、Jacobian、投影和关节步进缓冲区，直接计算
  各关节的世界坐标轴，移除重复临时矩阵。工作区不是求解器成员，已收敛种子跳过
  其构造，避免引入跨调用缓存失效问题。
- 新增矩形、秩亏与奇异值截断回归，并用 Eigen 分配守卫检查工作区从首次计算
  起不再申请堆内存。C++ 的误差阈值、步长和阻尼设置拒绝 NaN/无穷值；失败
  IK 会清空距离输出，防止上次结果残留。
- 延长计时组并固定 CPU 亲和性后，合成 1/3/6/7/14 轴迭代用例加速
  **1.01–1.60 倍**，成功状态、FK 次数、位姿残差和关节校验和保持一致。
  已收敛种子耗时变化约在 **±6%** 内；收益主要来自需要迭代的调用。

Python **262 通过、10 跳过**，扩展性质检查 **1500 例通过**；核心 CTest
**7/7**、ASan/UBSan 与 Eigen 断言 **7/7**、含碰撞 C++ 配置 **8/8**。
中英文严格文档构建、Doxygen、Ruff 和 `git diff --check` 通过。

本轮还完成无碰撞、无 Python 的 Conan 离线打包及外部轨迹消费者验证；实际编译器
为 GCC 11.4。本机默认 Conan profile 标注为 GCC 12，此次结果只验证当前宿主机的
构建和消费链路，不作为 GCC 12 或跨机器 ABI 验证。GPU、远端 CI 尚未验证。

测量参数和完整结果见[第六轮技术记录](technology_roadmap.md#第六轮进展数值-ik-工作区与-tcp-修正)。

## 第七轮：模型查询扩展性与编译器一致性

- 指定基座到末端的链查询在大模型长路径上启用调用内增量名称索引，避免每个
  父节点都重复扫描完整模型。短路径继续直接查询，名称和父子关系的公开 C++
  修改在下次调用生效，重复名称仍采用首次匹配结果。
- 默认链选择在遍历中累计活动关节数、提前排除不受支持的分支，只重建最终
  获选路径。保持最大活动自由度、同分时先访问叶节点、末端固定变换的既有行为。
- 修复公开父子关系被修改成环后 `CreateKinematics()` 无限循环的问题：现在
  以模型节点数限制父链遍历，返回 `nullptr`。旧库在新增回归中超时，新库通过。
- 合成 64/256/1024 关节链创建分别加速 **1.14/1.99/8.52 倍**；七轴短链耗时
  基本持平。256 关节、1024 固定叶节点的模型加载耗时降低约 **8%**，链创建
  加速 **1.76 倍**。这是初始化阶段的大模型收益，不代表典型机械臂实时求解收益。
- Conan 工具链传递编译器元数据，CMake 在配置阶段拒绝类型或版本不匹配。
  构建脚本支持独立 host/build profile，使用临时 profile 显式选择 GCC 12，
  已在实际 GCC 12.3 上完成完整构建和安装包回归；没有修改全局 profile。
  此检查不覆盖预编译依赖的完整 ABI，旧工具链需重新生成才能启用。
- Conan 源码导出补齐基准目录，使导出源码也能启用全部 CPU 基准目标。

最终 Python **263 通过、10 跳过**，扩展性质检查 **1500 例通过**；GCC 11.4
及 GCC 12.3 核心 CTest 均为 **9/9**，诊断配置 **9/9**，含碰撞 C++ 配置
**10/10**。跳过项为该 Python 安装未启用的原生碰撞接口。GCC 12.3 离线
Conan 打包、四个 CPU 基准目标构建及外部轨迹消费者运行通过。
中英文 Sphinx 严格构建、Doxygen、格式与 Shell 语法检查均通过。

本轮测试、打包及测量明细见[第七轮技术记录](technology_roadmap.md#第七轮进展模型查询与编译器一致性)。

## 第八轮：路径平滑工作区与精确路点校验

- 修复输入边终点插值的舍入误差导致可行性误判：校验回调现在接收原始终点，
  内部点仍按分辨率采样，保持回调顺序、数量和截止时间语义。四组 Python 回归
  在旧版全部失败，修复后通过；新增 C++ 回归覆盖同一行为。
- 路径平滑引入调用内几何工作区，回溯搜索复用相邻边、二阶差分、梯度、方向
  和候选缓冲区。每个新路点都刷新邻边，支持原有的正反向扫描与候选回退。
- 通过完整目标差、中心有限差分和 Eigen 分配守卫验证工作区，新增随机混合
  关节拓扑和可选状态代价的性质测试，检查端点、关节范围与完整目标下降。
- 完整 C++ 合成路径优化在无校验场景加速 **1.61–2.12 倍**，加入轻量校验
  后加速 **1.31–1.72 倍**。前后版本的迭代/更新/校验计数、目标值、路径
  长度与校验和一致；未测量真实网格碰撞和 Python 回调的端到端收益。

## 第九轮：模型一致性与 FK 边界修复

- 统一数值、OPW、UR 构造时的关节模型校验，避免空模型的自由度下溢、六轴
  求解器的短节点列表，以及活动末端节点没有对应坐标导致的越界。SRS 同时检查
  末端类型。数值 `SetDOF()` 仅接受模型原有维度，其他值抛出 `std::invalid_argument`。
- `SetJointNode()` 拒绝非法布局并保留原配置；硬件限位更新也必须与用户限位有
  非空交集；C++ TCP 和用户坐标系拒绝非有限值及非法四元数。
- 单固定节点保留为零自由度模型，匹配目标时返回一个空关节配置，不匹配时直接
  失败，避免进入零列 SVD。解容器允许零维配置，仍拒绝同一集合中的维度混用。
- FK 增加模型维度和算术溢出保护。有限输入也可能使旋转向量范数或移动量溢出，
  现在返回失败并清空位姿列表；六个 Python 回归在修改前均因未抛异常而失败。

验证：Python **274 通过、10 跳过**，深度性质检查 **1800 例通过**；GCC 11、
GCC 12 与 ASan/UBSan 核心 CTest 均 **11/11**，碰撞配置 **12/12**；中英文
严格文档构建通过。

实现、验证和运行成本见[第九轮技术记录](technology_roadmap.md#第九轮进展模型一致性与-fk-边界修复)。


本轮全量构建还发现并修复五次 Bezier 曲线的维度缺陷：笛卡尔分支固定读取三个
切向量元素，对一维/二维 Rn 越界，也与 SE3 的完整度量不一致。新增回归在旧版
触发 Eigen 断言，现统一长度系数的加权切空间计算，并校验低维及纯旋转曲线。


三轮交替 CPU 基准中，15 个 IK 用例结果完全一致，耗时变化约 **±1.5%**。
完整模型校验使链创建增加 **1.65%–7.71%**，七轴合成链约增加 **0.040 µs**。
最终 Conan 包及外部消费端通过，全量构建中的越界警告已消除。


## 第十轮：限位等价解的有界展开

- 修复大角度种子反复加减整圈而无法结束的问题，直接计算可行圈数；极大输入
  以实际旋转相位归一化，并校验返回角度的相位。
- 修复闭区间限位端点上的等价解丢失，新增四个旧版失败的 Python 回归。
- 以迭代组合生成替代递归及中间配置集合，复用当前调用内的候选和索引缓冲区。
- 默认最多生成 65536 个配置，C++ 可显式设置预算；超限清空结果并失败返回，
  避免异常限位造成无界组合展开。该失败不表示目标在几何上不可达。

完整说明与测量见[第十轮技术记录](technology_roadmap.md#第十轮进展限位等价解的有界展开)。
