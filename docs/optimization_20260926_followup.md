## 实现依据与边界

上一轮耗时分解显示，大尺度曲线的速度上界采样仍占构造耗时的大部分。
每个采样点会重复计算五个控制点差值，以及二、三阶导数使用的固定差值。
本轮把内置五次曲线的类型识别及这些差值移到采样循环外；参数相关的 Bernstein
表达式、运算顺序、采样网格、4096 个区间上限和极端比例回退保持原样。

缓存仅在单次构造采样中存在。标量查询仍使用较小的求值器，派生曲线仍逐次调用
虚函数，不缓存自定义行为，也不查询无关的位置。没有新增公开 API、公开对象
数据成员或运行时依赖。碰撞仍可选，测试使用合成路径和临时 URDF，不需要外部资产。

新增原生曲线与虚函数参考实现的速度上界对照，分别压低速度、加速度和 jerk 限位，
覆盖不同起始参数及 `1e-100` 至 `1e110` 的尺度；其中微小无效几何保留拒绝，
`1e110` 场景覆盖长度三次方溢出的稳定回退。已有自定义覆盖、非有限导数、
终点峰值及不前进采样网格回归继续通过。

## 配对性能

Ryzen 9 9950X、GCC 12，库为 Release `-O3`，调用程序为 `-O2`。固定 CPU 15，
编译结束并暂停本轮其他审计后，以八组交替顺序运行的中位数比较。
构造和速度上界采样各预热一次、测量 21 次。计时不作为 CI 门槛。
配对时用同一源文件独立以 `-O2` 编译，分别链接冻结库；常规 CMake 基准目标遵循所选构建配置。

新增 `trajectory_cap_benchmark` 用四个正弦路点、`0.005` 圆滑容差及单位限位，
再将几何、容差、限位共同放大 `1e4`。下表为梯形轨迹，不计几何路径创建：

| 维数 | 曲线速度上界采样，前 → 后 | 完整构造，前 → 后 | 完整构造耗时减少 |
| --- | ---: | ---: | ---: |
| 2 | 174.877 → 153.140 µs | 228.543 → 208.180 µs | 8.9% |
| 7 | 841.600 → 406.034 µs | 978.639 → 540.685 µs | 44.8% |
| 20 | 1610.767 → 896.123 µs | 1818.646 → 1099.213 µs | 39.6% |
| 32 | 2421.653 → 1364.070 µs | 2688.770 → 1636.160 µs | 39.1% |

这两项分别计时，其比例仅用于定位瓶颈，不是构造函数内部的插桩结果。
64 个普通尺度路点中，单独测量的采样加速约 1.19–1.85 倍；其原有占比很小，
不能把采样加速直接当作完整构造加速。

原有 32 个完整构造工况的加速比为 **0.955–1.027 倍**，16 个查询工况为
**0.992–1.031 倍**；24 个约束报告工况为 **0.969–1.019 倍**，全部校验和一致。
普通尺度总体变化较小，部分工况略慢。
例如 7 维、64 路点圆滑 Double-S 为 `906.642 → 902.980 µs`，
梯形为 `807.274 → 803.096 µs`。这些测量的调用方式与新增瓶颈基准不同，分别保留原始数据。
全部八组、32 个构造工况、16 个查询工况及 10 个瓶颈工况的时长和校验和均一致。

最终基准还包含两个 SE3 场景：使用三维正弦平移和固定的平滑旋转，放大场景只
缩放平移、圆滑容差及全部六个限位，旋转幅值不变。这是明确指定的工作负载，
不代表位姿的单位换算；两版输入完全相同。

| SE3 梯形场景 | 采样，前 → 后 | 完整构造，前 → 后 | 完整构造加速比 |
| --- | ---: | ---: | ---: |
| 64 路点、平移尺度 1 | 458.805 → 68.049 µs | 4792.681 → 4387.153 µs | 1.09 倍 |
| 4 路点、平移尺度 10000 | 4790.437 → 358.504 µs | 5754.443 → 1317.617 µs | 4.37 倍 |

SE3 控制点差值涉及位姿运算，复用收益较大。这个性能对照不替代 SE3 导数的物理正确性验证。

另用上一轮的二维 Python 大尺度路径复测，包含绑定和几何创建：梯形
`0.22838 → 0.20396 ms`，Double-S `0.22143 → 0.19679 ms`，约 **1.12 倍**，时长不变。
这是四个路点 `[[0,0],[1,1],[2,0],[3,1]]`、限位 `[1,2]` / `[2,3]` / `[3,4]`、
容差 `0.1` 共同放大 `1e4` 的场景，与上表的正弦路径不同。

分阶段对照还确认了二、三阶控制差值缓存的增量收益：7 维大尺度场景仅复用一阶
控制差值时，完整构造约 `691.699 µs`，加入高阶差值缓存后约 `542.335 µs`。
二维增量接近零，因此不能把高维收益推广到全部场景。

  --distribution rescaled-stress --seed 20261101 --cases 100000 \
  --samples 1001 --phase-samples 129 --check-continuity

  -o '&:with_collision=False' -o '&:with_cuda=False' \
  -o '&:with_tests=True' -o '&:shared=True' -c tools.build:jobs=2
