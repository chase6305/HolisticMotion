# 轨迹数值边界与构造优化（2026-09-26）

本轮从 `404762a` 接续[上一轮报告](optimization_20260925_second_followup.md)，
工作窗口为北京时间 02:22–04:22。实现位于 `perf/numerical-query-optimization`，
对应面向 `main` 的 [PR #3](https://github.com/chase6305/HolisticMotion/pull/3)。
以下区分本轮增量和整个 PR 的比较，原始 `main` 为 `e806b55`。

## 修复及优化依据

| 问题 | 处理及验证 |
| --- | --- |
| 用节点前的有限时间偏移检查连续性，遇到大 jerk 或长时钟会把正常变化误报为跳变 | 直接计算相邻多项式的单侧端点，并在真实几何边界选择阶段所接近的一侧；保留原有连续性阈值，增加真实跳变、反向运动及转折点回归 |
| 接触的 Bezier 过渡在坐标抵消后留下约 `1.39e-12` 的假直线，任意切向量产生约 153 的速度跳变 | 几何连接的舍入预算包含原始路点幅值；精简为四路点回归，覆盖正反向、两种剖面、三种尺度及减速 |
| 梯形峰值与端点速度极近时，加速阶段不能推进长时钟 | 原合并失败后，只尝试一次将峰值降至较大的端点速度；逐阶段核验实际时间戳上的积分位移，不能满足原误差预算仍拒绝 |
| 停车末端的速度二次式舍入到略小于零，丢失进入直线的归属，提前使用反向直线切向量 | 仅当全部可能回退位移仍在原几何舍入预算内保留阶段归属；更大回退仍按位置查找。13 路点回归在旧代码失败、新代码通过 |
| 曲线速度采样重复开根、求幂及计算几何导数 | 先归约正常比例再求根；溢出/下溢继续走稳定回退。内置五次曲线共享导数计算，自定义派生类保留虚函数行为 |
| 构造限位采样已知所属时间阶段，仍每次二分查找样条 | 使用已知阶段并保留原节点吸附规则；超出阶段时回退原查找 |
| 外部连续性审计按请求偏移计算导数预算，忽略长时钟减法舍入 | 使用实际采样时间差，并同时检查原生连续性报告；新增宽尺度分布和独立报告审计工具 |

停车回归的原始 27 路点输入来自种子 `20261030`、第 `82082` 例。
末端速度最小值约 `-2.01e-21`，其全部可能回退位移不足 `2.3e-26`；
原算法因此切换到反向几何，加速度跳变约 `6.63e-5`。修复后最大跳变约
`3.05e-12`，20,001 个全局样本、每阶段 1,001 个样本及两种连续性检查均通过。
这项修复改变该案例的限位缩放，时长从 `22224.6822` 减至 `22224.0317` 秒；
不能将此案例描述为仅更快地计算完全相同的时间律。

- [double_s_rounded_stop_ownership.json](../benchmarks/fixtures/double_s_rounded_stop_ownership.json)：停车速度最小值的舍入。

- [trapezoidal_clock_precision_rejection.json](../benchmarks/fixtures/trapezoidal_clock_precision_rejection.json)：历史拒绝输入现已通过。
- [trapezoidal_lower_peak_precision_rejection.json](../benchmarks/fixtures/trapezoidal_lower_peak_precision_rejection.json)：降峰后仍超出积分预算，继续拒绝。

## 配对性能

使用 Ryzen 9 9950X、GCC 12，库为 Release `-O3`，基准调用程序为 `-O2`。
比较本轮起点 `404762a`、最终实现 `c460f80` 及原始 `main`；固定 CPU 15，
暂停本轮其他审计且编译已经结束，以八组交替顺序运行的中位数比较。
构造与报告各预热一次、测量 21 次；查询每组 20,000 次，预热一组后取七组中位数。
加速比为基准耗时除以当前耗时，小于 1 表示更慢；计时不作为 CI 门槛。

| 7 维场景 | 本轮修改前 | 当前 | 本轮加速比 |
| --- | ---: | ---: | ---: |
| 4 路点圆滑 Double-S 构造 | 98.377 µs | 88.508 µs | 1.11 倍 |
| 64 路点圆滑 Double-S 构造 | 1077.885 µs | 936.391 µs | 1.15 倍 |
| 64 路点圆滑梯形构造 | 966.803 µs | 829.634 µs | 1.17 倍 |
| 64 路点组合状态查询 | 116.124 ns | 104.128 ns | 1.12 倍 |
| 64 路点 Double-S 约束报告，2 个均匀样本及阶段端点 | 67.313 µs | 53.261 µs | 1.26 倍 |
| 64 路点 Double-S 约束报告，2001 个均匀样本及阶段端点 | 334.970 µs | 306.256 µs | 1.09 倍 |

32 个构造工况的本轮加速比为 **0.96–1.33 倍**，16 个查询工况为
**0.96–1.12 倍**，24 个报告工况为 **1.00–1.26 倍**（最小值约 0.9993）。
并非每个工况都更快。八组对照中，全部构造和查询工况的时长及校验和均与本轮起点一致。
构造基准不计路径几何创建；报告基准不计轨迹构造和 Python 绑定。

四个二维路点 `[[0,0],[1,1],[2,0],[3,1]]` 的 Python 构造另行测量：
速度/加速度/jerk 限位分别为 `[1,2]`、`[2,3]`、`[3,4]`，圆滑容差为 `0.1`，
几何、限位及圆滑容差一起放大 `1e4`。相同固定核和八组交替运行，
每次预热一次后取十次中位数，梯形为 **0.6020 → 0.2334 ms（2.58 倍）**，
Double-S 为 **0.5925 → 0.2267 ms（2.61 倍）**，时长不变。
这个测量包括 Python 绑定和路径几何创建，不代表普通长度路径的收益。

相对原始 `main`，7 维、4 路点无圆滑 Double-S 构造约 **71.0 倍**；
7 维、64 路点圆滑 Double-S 为 `1049.861 → 936.391 µs`，耗时减少约 **10.8%**。
同场景梯形为 `746.190 → 829.634 µs`，仍慢约 **11.2%**；20/32 维长圆滑梯形
仍慢约 **24.5%/31.5%**。额外的局部限位检查仍有代价；整个 PR 的几何和时间律
修正也意味着不能假设与 `main` 的输出全部相同。

样条阶段复用单独对照了 20,000 条混合分布 Rn 轨迹：时长、断点和所有采样状态的
二进制摘要完全一致。另有 2,000 条含平移和旋转的 SE3 轨迹与本轮起点对照一致，
覆盖两种剖面、有无圆滑及笛卡尔标志；这些针对实现优化的等价性检查不替代极端
几何修复后的独立不变量验证。

假直线，2 条是舍入停车阶段失去几何归属。另有 84 条输入恢复构造，未新增告警或

另一组独立宽尺度密集审计使用 NumPy **2.2.6**、种子 `20261025` 至 `20261032`，
每种子 100,000 条，同样使用 1,001 个全局样本、每阶段 129 个样本及两种连续性检查。
最终为 **799892 通过、20 构造拒绝、87 原生报告连续性告警、1 外部连续性失败**，
没有采样限位、端点或非有限状态失败。这组审计发现并验证了停车几何归属修复；
补充修复前后重跑相同输入，只消除了 `20261030 / 82082` 这一条失败。

保留的外部连续性失败是种子 `20261026`、第 `56910` 例梯形轨迹，其原生报告也
指出速度不连续，最大速度跳变约 `1.19e-6`；外部速度变化比值约 `1.000805`，
超过既定阈值。该案例在本轮起点也失败，与长时钟的浮点精度有关。它没有被算为通过。

剩余 61 条报告告警包含 17 条 Double-S 和 44 条梯形。把相应导数跳变除以
“下一阶导数采样峰值 × 总时长的一个浮点间距”，最大比值约 0.536，与绝对
时间戳量化的量级一致；这些仍保留为失败。本轮没有放宽
`1e-7 * max(1, limit)` 的报告连续性阈值。有限精度仍限制部分长时钟轨迹，
例如 `[0, 1e12, 1e12+1]` 的一维路径配合速度/加速度/jerk 限位 `1/3/10`，
可构造但原生报告会指出连续性问题。构造成功不代表报告中的所有条件都通过。

报告审计只请求三个均匀样本并检查阶段端点，不等同于密集物理可行性审计。
任一构造拒绝、不变量失败或连续性告警均使命令返回状态码 1；不得将失败输入算作
通过。JSON 保留各类前十例完整输入，按相同分布、种子、NumPy 版本及索引重放。
宽尺度分布将几何、限位和圆滑容差同步乘以 `1e-2` 至 `1e4` 的随机因子。

采样不能证明采样点之间持续满足约束，也不证明碰撞自由。CUDA/GPU 与真实机器人
硬件未验证。原始 `main` 头文件的消费程序检查只覆盖具体测试程序，不构成通用 ABI 证明。
