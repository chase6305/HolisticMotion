## 改动

对每个指数因子 `B = Exp(beta * xi)`，其速度、加速度和 jerk 都是同一旋量
`xi` 的标量倍数。设 `U = Ad(B^-1) vA`、`A1 = Ad(B^-1) aA`、
`J1 = Ad(B^-1) jA`，先计算 `C = [xi, U]`，再利用李括号的双线性：

```text
v = U + beta' xi
a = A1 - beta' C + beta'' xi
j = J1 - 2 beta' [xi, A1] + (beta')² [xi, C] - beta'' C + beta''' xi
```

每个需要坐标转换的因子从四次李括号减少到三次。没有除以 `beta'`，因此
端点处导数系数为零时仍使用同一公式。指数变换、位姿插值、归一化顺序、
纯平移差分、自定义虚函数分派及所有采样网格保持原实现。

公共 API、对象布局和依赖均未改变。SE3 速度仍为本体旋量，二、三阶导数
仍为该坐标向量的参数导数。浮点加乘顺序改变，SE3 导数和时间分配不承诺
逐位一致；Rn 的求值公式没有改动。
