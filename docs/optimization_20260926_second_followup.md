# 组合限位检查优化补充报告（2026-09-26）

本轮从 11:27:25 UTC 开始，继续优化轨迹构造中的组合关节限位检查。
对照分支起点为 `6f28365`，其生产实现为 `3a9f77e`；本轮生产实现为 `866355a`。
这是相对上一轮的增量比较，没有重新测量原始 `main`。

## 实现与边界

- 每次限位检查只维护一个当前几何段的局部求值器，复用内置五次曲线的一至三阶固定控制差值。
  几何段切换时重建，并用强引用保证所借用控制点的生命周期。
- 只缓存精确的内置曲线类型。自定义派生段仍执行位置和三阶导数的虚函数。
  无效原生曲线在访问控制点之前校验，位置非有限时仍拒绝构造。
- 位置继续按原顺序执行 Lie 群运算，特别是 SE3 的旋转复合；不合并为可交换的向量运算。
  保留链式法则表达式、溢出/下溢回退、几何归属、采样密度和所有容差。
- 标记共用链式法则函数为 `inline`，避免提取共用代码后在状态查询中增加不必要的调用。
  不添加强制内联、编译器专用属性、持久缓存或公共对象字段。
- `trajectory_cap_benchmark` 新增 `limit_us` 列。它在完整构造之后重新执行限位检查，
  要求检查前后时长完全相同；这是独立计时，不是对构造函数内部耗时的插桩。

库的公共 API、对象布局和运行时依赖没有变化。碰撞仍为可选组件；不需要机器人资产路径或下载。

## 配对性能

Ryzen 9 9950X、GCC 12，库使用 Release `-O3`、调用程序使用 `-O2`。
编译结束并暂停本轮审计后，固定 CPU 15，进行八组交替顺序的配对测量。
不停止用户的其他任务；不将计时作为 CI 门槛。每次 C++ 构造/限位/报告测量预热一次，
再取 21 次调用的中位数；查询基准每次测量 20000 次调用、重复七轮。

Rn 几何、限位和圆滑容差一起缩放；SE3 保持旋转幅值固定，只缩放平移、圆滑容差和六个限位。
后者是指定的工作负载，不是位姿单位换算。前置速度上界采样的主要优化已在上一轮完成。
重复限位检查耗时与完整构造耗时的比例仅用于诊断，不能视为精确的内部占比。

现有 32 种构造工况涵盖 2/7/20/32 维、4/64 路点和两种时间剖面：

- 16 种圆滑路径的加速比为 **1.104–1.506×**。
- 16 种纯直线路径为 **0.903–1.059×**，并非全部更快。最慢的相对变化为
  2 维、4 路点、`trapezoidal`：
  0.9815 → 1.0870 µs。
- 16 种查询为 **0.966–1.001×**；24 种约束报告为 **0.950–1.010×**。
  对固定缓存不生效的查询不能承诺加速。
- Python 构造还包含绑定和几何创建，八种尺度/剖面组合为 **1.036–1.174×**；
  不应直接与 C++ 构造数字混用。

所有配对中的时长、状态/报告校验和、曲线速度上界校验和保持一致。
曾试验按直线类型或已知阶段归属分流，但整体收益不稳定，因此没有保留。
初版共用函数引入的 7 维报告回退促使本轮检查编译结果，并采用标准 `inline` 声明；
中间实验数据单独保存，不替代这里的最终版本数据。

## 数值验证

- 20000 条混合普通/压力 Rn 输入，种子 `20261023`：全部接受，时长、阶段节点及
  129 个全局点加所有节点的完整状态签名，与上一版逐字节相同。
- 100000 条重缩放 Rn 输入，种子 `20260926`、NumPy 2.2.6：99998 条接受、2 条拒绝。
  同时比较原生约束报告；签名及拒绝结果与上一版相同。
- SE3 普通 2000 条全部接受；宽尺度 4000 条接受 3994 条、拒绝 6 条。
  两组签名相同，覆盖两种剖面、Cartesian 选项及接近 ±π 的旋转。
  等价性本身不证明 SE3 导数的独立物理正确性。
- 另有 2000 条多段几何对照，覆盖 Rn 2/7/20/32 和 SE3 的正向、反向、折返、三次时间律。
  缓存原生曲线与逐次虚函数求值的时间缩放和 130 点完整状态一致。
- 独立密集审计种子 `20261101`：100000 条重缩放 Rn，每条 1001 个全局点、每阶段
  129 点，并检查外部及原生连续性。结果为 **99987 通过 / 3 拒绝 / 10 原生连续性告警**。
  完整失败输入和诊断与上一版逐字节相同，没有新增限位、端点或非有限状态失败。

10 条原生连续性告警仍作为失败保留，没有放宽阈值或修改报告来隐藏它们。
此前文档中的百万级审计属于旧版本历史证据，本轮不声称重新运行过那些全部样本。
采样和等价性检查不构成连续时间约束、避碰或硬件安全的证明。
