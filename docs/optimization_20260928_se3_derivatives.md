# SE3 曲线导数一致性优化（2026-09-28）

本轮修复上一轮留下的 SE3 曲线内部导数问题。基线为 `2ad7bbd`（生产代码
`e814f27`），本轮生产提交为 `8374e65`。这是增量比较，不是相对原始 `main`
的性能比较；先前各轮的大规模审计也不计作本轮重跑。

## 修复与接口约定

SE3 二次和五次曲线的位姿由累积指数乘积组成：

```text
Q(s) = Q0 product_i Exp(beta_i(s/L) xi_i)
xi_i = Log(Q_i^-1 Q_(i+1))
```

旧实现只将控制增量按 Bernstein 基函数相加，遗漏了非交换变换之间的坐标
转换，因此返回的切向量不等于实际位姿曲线的一阶导数。新增的确定性回归在
基线上复现约 `0.0188` 的归一化位姿差分误差。

新实现通过相邻因子的逆伴随变换传播本体速度，并对传播公式继续求导。
设 `U = Ad(B^-1) vA`、`A1 = Ad(B^-1) aA`，则乘积 `AB` 的导数为：

```text
v = U + vB
a = A1 - [vB, U] + aB
j = Ad(B^-1) jA - 2[vB, A1] + [vB, [vB, U]] - [aB, U] + jB
```

这里的速度为 `vee(Q^-1 dQ/ds)`，坐标顺序为线速度、角速度；二阶和三阶
导数是该坐标向量对路径参数的导数。时间映射、状态查询、限速采样和约束
报告统一采用同一约定。它们不是世界坐标系的位置导数：例如世界平移加速度
为 `R * (a + omega.cross(v))`。英文、中文文档及公共头文件已说明这一点。

二次 SE3 曲线现在覆盖 `GetTorsion`，返回一般情况下非零的三阶导数。
已有方法签名和公共对象尺寸未改变，但计算结果及由此确定的轨迹时长可能改变。
C++ 使用方应使用更新后的头文件重新编译，尤其是直接调用具体二次曲线类型
的 `GetTorsion` 时；旧头文件仍可能直接调用原有的内联零值实现。

组合查询共用指数变换；只有精确匹配的内置曲线使用共享求值，自定义子类仍
调用其虚函数。Rn 保留原有 Bernstein 差分公式。纯平移 SE3 也先计算控制差分，
使等距直线的二阶、三阶导数保持精确零值，避免短段放大浮点抵消噪声。

## 数值证据

- 新增 `se3_derivative_smoke`：48 组确定性输入，覆盖纯平移、同轴旋转和
  非交换 SE3 曲线；二次与五次曲线的内部点、端点单侧差分、两种差分步长、
  非匀速时间映射、1.7 倍时长、缓存报告和自定义虚函数覆盖。另有旋转后局部平移的闭式公式回归，验证二次曲线非零三阶导数。端点使用四阶
  单侧差分，避免低阶截断误差在短曲线上被放大。
- 复用上一轮独立的完整伴随矩阵参考实现，2,000 条路径、12,000 个内部点。
  本体速度、二阶和三阶导数的最大归一化差异分别为
  `2.91e-14 / 4.33e-14 / 1.07e-13`。相对步长 `1e-5` 时，参考实现与有限
  差分的最大差异为 `6.37e-9 / 4.74e-10 / 9.71e-10`。该组复核与上一轮使用
  同一输入集，不作为独立新增样本计数。
- 新种子 `20260930` 的 10,000 组三控制点生成 20,000 个有效曲线（二次、
  五次各一个），覆盖尺度 `1e-2` 到 `1e4`、普通旋转、纯平移和同轴旋转。
  每条曲线检查五个内部位置及两个步长；一阶导数另外用齐次变换的旋转矩阵、
  平移向量直接差分，避免依赖位姿对数作为唯一验证方式。
  步长 `1e-4` 的前三阶最大归一化差分误差分别为
  `9.34e-10 / 4.26e-11 / 9.55e-9`；步长 `1e-5` 为
  `9.53e-9 / 3.95e-10 / 9.55e-8`。最小步长的三阶最差值来自纯平移二次
  曲线常量二阶导数的差分舍入噪声。
- 新种子 `20260929` 的 5,000 个 SE3 完整轨迹，含接近半周的旋转、不同
  尺度、Double-S 和梯形时序。基线与候选均拒绝 337 个相同输入；剩余
  4,663 个没有非有限状态、报告超限、速度连续性失败或 Double-S 加速度
  连续性失败。梯形加速度跳变属于预期行为。原速及 1.7 倍时长的报告最大
  利用率为 `0.990099373`。
- 从上述输入按编号每 37 个取一个，得到 136 个样本，其中 10 个仍被拒绝。
  对 126 个有效轨迹在两个时长下各取 20,001 点并检查阶段端点，均通过；
  最大利用率为 `0.990099136`。这是前述集合的子集，不重复计算独立样本数。
- 另一个 5,000 路径配对检查中，路径长度及每条路径 129 个位姿样本的
  二进制摘要全部相同。修复改变导数和时间分配，不改变这组路径的位姿插值。
- 20,000 个 Rn 完整输出摘要与本轮基线逐位一致，没有拒绝或输出差异。

归一化误差使用 `norm(actual-expected) / max(1, norm(expected))`。
差分误差包含截断和浮点误差，不等于解析实现的误差界。
原生曲线仍采用有限密度的限值采样；上述数据不证明任意输入或采样点之间的
连续约束满足，也不证明碰撞自由。没有新增隐式机器人资源下载。

## 性能

其他用户任务未被暂停。原始数据、每组比值、最小/最大值及相对 MAD 均保留。

此外，没有圆滑曲线的 SE3 密集报告也慢约 15%–17%，其几何算法并未改变；
该回退的具体原因尚未定位，不归因于新增的曲线求导工作。
