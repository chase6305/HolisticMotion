# 轨迹时间参数化

<div class="language-switcher"><a href="../en/trajectory.html">English</a> · 简体中文</div>

HolisticMotion 将几何路径与时间参数化分开处理。`ToppraTrajectory` 在不改变
关节路径几何形状的前提下，对已有路点路径进行满足速度、加速度限制的重定时。

```python
from holistic_motion.trajectory import ToppraTrajectory

trajectory = ToppraTrajectory(
    [[0.0, 0.0], [0.4, -0.2], [1.0, 0.5]],
    max_velocity=[1.0, 0.8],
    max_acceleration=[2.0, 1.5],
)
times, position, velocity, acceleration = trajectory.sample_uniform(200)
```

路点、约束和时间参数化结果数组都是自包含的不可变快照。`sample()` 与
`sample_uniform()` 返回新的数组，应用可以自由修改而不会影响轨迹对象。

算法以路径速度平方为状态，先反向传播可控区间的上下界，再正向选择可达的最大速度。
运行时不依赖上游 TOPPRA 包，也不需要额外 LP/QP 求解器。

`start_path_velocity` 和 `end_path_velocity` 指归一化弦长参数的起止速度，
默认均为零。可行时结果保留指定值；在当前网格的约束下不可行时抛出 `ValueError`。
求解完成后不会通过整体时间缩放修改这些边界值。

轨迹图表按左臂、右臂标签页分组，图例使用统一颜色的 `J1`–`J7` 短名称，并提供
完整 URDF 关节名映射表。点击图例条目可以单独查看一条曲线。

`--urdf-path` 和 `--urdf_path`。在已经编译的源码仓库中直接执行时，Demo 会
自动进入 `scripts/run.sh` 环境。

路径插值器使用关节空间自然三次样条。每段通过路径一阶导数的解析极值限制速度，
通过二次加速度多项式的 Bernstein 系数限制加速度，覆盖整个区间及节点两侧。
这些区间约束偏保守，不能保证连续问题的全局时间最优；增加 `grid_size` 可以减少
保守程度。自定义网格端点与 0、1 的误差不超过 `1e-12` 时，会在不修改输入的
前提下归一到准确端点；内部网格点必须位于路径范围内。`ToppraResult` 同时
校验路径速度、加速度和时间数组的一致性；减速到零附近的动力学误差按等式
各项的尺度判断，避免更换时间单位后因大数相消误拒合法结果。

原生 Bezier 路径遇到掉头路点时，即使启用了圆滑过渡，也保留准确路点和直线
连接；Double-S 和梯形时间参数化会先停下再反向。二次曲线使用当前拐点的
控制点与归一化方向计算过渡距离，使容差随长度单位一致缩放。完整路点调试
字符串仅在开启 Debug 日志时格式化。
五次 Rn 路径接近掉头时，如果对称圆滑段的长度不超过现有 `1e-5` 阈值，
也会保留路点并采用停止后的直线连接，避免整条轨迹因短圆滑段构建失败。

C++ 的 `PathSegBezierCurve5th` 对曲线长度的各项系数统一使用完整切空间度量，
SE3 路径包含旋转分量。笛卡尔标志不会将切向量截取为三维，因此一维和二维 Rn
曲线也可安全使用该标志；沿固定轴的直线纯旋转曲线与线段采用相同的路径长度定义。

五次 Bezier 的切向量、二阶和三阶导数使用控制点逐阶差分与 Bernstein 基
计算，避免展开多项式系数相消后，再除以短曲线长度的平方或立方而放大误差。
控制点增量完全一致的直线因此保持零二阶、三阶导数，无须设置导数截断阈值，
也不会因虚假的高阶导数产生额外限速。输入及控制点本身的舍入误差仍受普通
浮点精度限制。

相邻曲线相接时，判断残余直线是否属于舍入误差会同时参考原始路点和裁剪后
控制点的大小，覆盖大坐标相消后连接点接近原点的情况，避免数值残差形成
方向任意的极短计时段。实际存在的最后一段直线仍保留，以到达请求的终点。

对于长度极大的有效段，二次曲线的二阶导数和五次曲线的三阶导数在长度的
平方或立方溢出时，改为逐次除以长度，保留本来仍可表示的非零导数，避免
除以无穷后误变为零。普通长度沿用原有的归一化计算；构造有效性检查仍适用。

直接查询 C++ 原生直线和 Bezier 路径段时，与完整路径采用相同约定：非有限
参数抛出 `std::invalid_argument`，对无效段使用有限参数查询抛出
`std::logic_error`；有效段仍将有限越界参数夹紧到段内。有效段要求起止
参数有限、长度有限且非负。零长度二次 Bezier 无效；零长度直线段仍可作为
常量配置查询。五次曲线拒绝非有限的端点导数模长及溢出的控制点。
直接构造路径段后，应先检查 `IsValid()`。

五次路径段的长度求解避免在二次方程公式中将两个接近的数相减：先根据
符号计算一个根，再由两根之积恢复另一个根，提高方程接近线性时的精度。
原有的近线性判定阈值和取较大根的规则保持不变，非正或非有限长度仍会被拒绝。

对于原生 Double-S 和梯形轨迹，`state(t)` 同时返回位置、速度、加速度和 jerk，
共用一次时间样条定位和一次几何路径段选择；批量采样也使用此组合查询。
内置直线和五次曲线段还会共用几何导数计算；自定义路径段子类继续调用其
各阶虚函数。各阶独立查询仍然可用，并采用相同的时间缩放。

C++ `PSpline` 的内部节点采用右连续语义，有限的越界查询夹紧到时间范围内。
节点吸附容差由实际局部时间戳和相邻区间长度决定，不设置一秒的尺度下限；
极短轨迹仍能查询节点之间的状态，后续长段也不会吞掉前面的短段。
非有限查询时间抛出 `std::invalid_argument`；追加分段若使累计时间戳溢出，
或因浮点精度而无法前进，`PushBack` 返回 false 并保留原样条。

Double-S 端点速度调整依据加速度和 jerk 限制下的最短过渡距离，需要调整时
最多执行 64 次二分。速度差小并不意味着短路径可行。各相位在积分前检查时长：
舍入量级的负零相位归零，明显为负的相位被拒绝；时间样条插值也拒绝超过
舍入容差的倒退时间戳。端点速度修正可能改变已有路径的时间参数化结果。

时间样条转换保留所有正时长相位，包括短于 10 微秒的相位；丢掉短加速度或
jerk 相位会改变终点状态及总时长。大时间缩放因子逐阶作用于导数，以保留仍可
表示的微小数值；会使总时长溢出的更新被拒绝，原来的时间缩放保持有效。
链式法则中的标量速度平方或立方若溢出或下溢，也改用逐次乘法，保留与
几何导数组合后仍可表示的结果。jerk 混合项先合并标量因子；中间乘积超出
正规数范围时，分开累计二进制指数，避免大曲率或极小标量乘积丢失可表示的结果。

原生轨迹的约束报告先计算归一化比例，再生成采样时间，避免有限的大时长在
中间运算中溢出。构造时的限位采样也先归一化区间长度，再确定采样数量，避免
极小的非正规时长所对应的采样步长下溢为零。连续性诊断直接计算相邻相位的
局部时间端点，并使用各相位从内部接近节点时的几何方向；高 jerk 或较大的
累计时钟不会再把有限采样间隔内的正常导数变化误报为跳变。峰值限位仍汇总
离散采样和相位端点，不构成连续时间约束的证明。

若采样状态的位置或任一阶导数含非有限值，约束报告抛出 `std::runtime_error`
（Python 中为 `RuntimeError`），避免峰值汇总静默忽略 NaN。构造时若加速度或
jerk 利用率溢出，则先对导数及其上限取平方根或立方根，再计算比值，避免
误拒绝仍能用有限时间缩放满足的约束。有限的加速度和 jerk 比值先汇总最大值，
再统一取根，避免每个采样点重复求根。有限的限位倒数在向量归约中复用；
倒数或乘积无法表示时，仍回退到除法。这些算术优化保持采样网格，浮点舍入
可能改变最终缩放系数的末位。

对于完全由直线段组成的路径，轨迹查询保留各时间相位所属的几何段。停顿拐点
前的路径位置可能提前舍入到拐点，但速度、加速度及 jerk 仍使用当前进入段的
方向；到达时间节点时，按时间样条既有的右连续规则切换到下一相位。独立、
组合及批量查询在时间缩放后也共用这一选择。包含混合曲线的路径中，若单调直线
相位的首尾状态标识同一直线，且落在其几何范围及受相邻段长度约束的坐标舍入
范围内，也保留这一归属。归属不明确或跨曲线的相位仍按路径位置定位。
在直线直接相接的停顿点，即使终止状态已替换为下一直线的初始状态，进入段的
最后一个相位仍保留原直线，避免末段位移的坐标舍入提前切换导数方向。
修正导数峰值后，原先因方向错配
产生的额外全局减速可能减少。

梯形剖面生成也保留每个正时长的加速、匀速及减速相位，包括短于几何容差的
相位。加速度正负号依据实际端点速度与内部目标速度的差值确定；匀速时长由
总距离扣除两个变速段的距离后计算，也适用于标量端点速度高于内部限速的
情况。各相位积分因此与报告的终点位置、速度一致，后续仍执行全局限位缩放。

距离不足以达到请求的标量端点速度时，梯形剖面用距离除以平均端点速度计算
时长，避免速度差舍入为零后丢失经过时间。短减速段保留请求的端点速度，
先计算所需加速度，再由全局缩放恢复限位。若结束时间戳无法表示，则在输出
相位或改写请求的末速度之前拒绝结果。

梯形剖面峰值速度未达到限速时，变速时长采用有理化的距离公式，避免两个接近的速度
相减，保留非零端点速度下短区间的经过时间。峰值恰好等于限速时采用限速
分支计算，保留匀速行进；峰值计算中的平方项溢出或进入非正规范围时，改用
缩放范数计算。

没有匀速段的凸形 Double-S 剖面，对静止到静止的运动使用解析解；一般情况
单调求解高于较大端点速度的增量，避免四次幂中间量及反复降低加速度上限。
变速时间先取根再求比值，使共同坐标尺度很大或很小时仍保留有限时长。
若峰值舍入为端点速度，则拟合单向过渡，核验实际速度变化，并约束实际加速度
与 jerk；相同端点速度也可采用匀速段。给定距离内不可达的端点速度仍须调整，
入口速度调整仍会向上游回溯。零长度标量剖面被拒绝；端点高于限速的凹形剖面
保留独立处理逻辑。

梯形相位列表在整条剖面通过状态有限性及时间戳检查后才输出。若正时长相位
无法推进时间戳、却改变了位置或产生实质速度变化，则必须构造有效替代段，
否则生成失败并返回空结果。
若位移不超过当前路径区间长度乘以 64 倍机器精度，且速度变化也不超过端点
速度尺度乘以 64 倍机器精度，可保留
当前状态并省略该舍入相位。这允许相邻路径段的限速存在几个 ulp 的误差，
同时避免绝对容差吞掉小单位下的真实运动。Double-S 和梯形单步积分
在 jerk 为零时跳过位置的三次项，避免零乘以溢出的时间立方产生 NaN。

梯形剖面首尾无法表示的变速段，可以与相邻匀速段合并为匀加速段：用位移
除以平均端点速度计算时长，再以实际存储的时间戳之差计算加速度，从而
真正完成速度调整，避免同一时间戳上的速度跳变。替代段必须满足加速度
上限，积分位移处于既有相对舍入范围，时间修正受时间戳舍入及实际平均速度
变化对应的修正量共同约束；该修正相对于原匀速时长不一定很小。
两端变速段都需要合并时可共用一个替代段。没有匀速时间、状态非有限，或
超出时间、位移、加速度界限时，仍清空结果并返回失败。

若合并无法满足位移预算，且原峰值高于两个端点速度，可将峰值降到较快的
端点速度并重新规划一次，移除无法表示的微小速度突起。重试保持端点速度和
原有限位，对每个替代相位按实际存储时间戳重新检查位移预算；不满足时仍拒绝。

Double-S 也在所有相位状态通过检查后才输出剖面及调整后的端点速度。时间戳
不能推进的相位必须保持位置、速度、加速度均不变，否则生成失败，清空输出并
保留请求速度。零时长过渡仍保留回溯所需的八状态布局。三角形变速边界处，
若匀加速平台时长处于变速段时长及端点速度误差除以加速度所传播的舍入范围，
位移不超过路径区间长度乘以 64 倍机器精度，速度变化满足同样的相对界限，
且加速度未变，则在时间戳无法推进时仅保留 jerk
切换，让同一时间戳的状态保持完全一致。真实平台和产生运动的 jerk 相位
仍不能绕过时间戳检查。需要降低起始速度的
有效剖面仍用于向前段传播调整；生成失败得到空剖面时则立即停止回溯。

回溯后，Double-S 根据各相位的相对经过时间和经过检查的匀速过渡，重新定位
后段时间戳。零长度过渡不除以速度，因此停驻连接仍保持有限。正间隔缺少
前进速度、时间戳溢出，或时间相位坍缩却改变位置、速度、加速度时，会拒绝
拼接。所有新时间戳检查通过后才替换原值。积分舍入范围内的微小负位置间隔
按零处理，避免生成倒退的过渡。

非零 jerk 的位置积分在时间立方或其与 jerk 的乘积溢出、下溢至非正规范围或零时，
改用尾数与指数缩放，保留中间值超出浮点范围但最终仍可表示的三次位移。
普通输入保留原有运算，零 jerk 仍跳过三次项。真实位移溢出继续产生非有限值，
由剖面校验拒绝。这项回退覆盖位置三次项。

位置和速度中的二次项在中间乘积超出正规范围时也使用指数缩放，避免极小
加速度或 jerk 先乘以 0.5 后被舍入，再被较长时间放大。普通输入保持原乘法
顺序；真实溢出继续产生非有限值。线性项及各积分项之间的相加保留既有公式。

曲线限速采样检查参数区间及各采样点的切向量、曲率、扭率。区间无效或导数
非有限时，返回零允许速度，令轨迹构造失败。长度超过 40.96 的段使用最多
4096 个归一化采样区间，避免改变坐标单位导致预采样量无限增长；较短段保留
0.01 步长（不足该长度的段使用整段长度）。两种网格都检查精确终点。步长无法
推进存储的路径参数时仍拒绝，避免循环停滞。组合轨迹继续执行独立的关节限位检查。

每个有限且非零的导数都会参与采样限速，包括小于几何容差的导数，因为更小
的关节限制仍可能使其成为约束。曲率和扭率限速在限制与导数直接相除发生
溢出或下溢时，改为分别开平方根或立方根后再相除；普通比值保留既有运算。
这些仍是采样限速，后续继续执行全局限位缩放。

轨迹相位转为时间样条时，会检查每个状态的位置、速度、加速度和 jerk，包括
末状态与零时长过渡。任一状态存在非有限值，整个转换都会失败并返回空样条，
即使之前的相位有效也不保留部分结果。有限的零时长过渡保持原有处理方式。

路径级 `PathBase::GetPathSegmentAtS` 以及配置、切向量、曲率、扭率查询，对
NaN 和无穷大的参数抛出 `std::invalid_argument`。有限越界参数仍夹取到端点，
内部边界仍选择后续路径段。无效路径即使保留了路径段，按参数或索引查找也
返回 `nullptr`；其几何查询抛出 `std::logic_error`。

轨迹内部计算出的路径位置若非有限，仍视为求值错误（`std::runtime_error`）。
约束报告继续传播该错误，限位处理则将轨迹标记为无效并返回失败。

近重复点过滤只针对内部路点。即使最后一段短于几何容差，也保留用户请求的终点；
正长度直线段使用归一化的路径切向量。Python 构造器也接受短于该容差的非零两点运动；
完全重复的点仍无法构成运动轨迹。小于容差的圆滑段会在裁剪相邻直线之前关闭，
因此省略圆滑段不会留下位置跳变。

对于位于同一直线几何段内的时间段，限位检查直接评估端点和标量加速度的内部零点。
这些位置覆盖二次速度、一次加速度及常量 jerk 的可能极值，无需密集的均匀时间网格。
单调性检查也能识别带圆滑段路径中的直线时间段。当同一单调时间段跨越多个几何段时，
通过反求实际时间样条，在几何边界处细分检查区间。每个曲线子区间按时长分配采样，
且至少检查 65 个点，避免长时间段内部的短曲线峰值被遗漏；直线子区间仍检查解析极值。
自定义的非单调时间段沿用密集采样回退。曲线路径仍采用采样限位检查，不构成连续约束
的数学证明。

两种剖面构造前，连续曲线组的连接速度同时受两侧相邻直线的速度上限约束，
避免曲线与直线各自计算的限速因舍入而冲突，不提高任何一侧上限。

Double-S 将端点速度高于相邻段速度上限、且差值不超过该速度 128 倍机器精度的情况
视为同一数值上限，保留端点速度，避免对先前路径段做无意义的回溯。比较始终基于
原始上限，容差不会在两个端点间累加。更大的超出量仍会触发降速和回溯，组合轨迹
也仍需经过全局关节限位检查。

梯形剖面也按原始速度上限比较，使用 256 倍机器精度的相对范围，保留曲线和直线
连接处舍入等价的端点速度，避免产生时间戳无法推进的极短变速段；组合轨迹
仍执行全局关节限位检查。

Double-S 末段若必须降低入口速度，会将调整回传给前面的阶段，避免曲线与直线
连接时速度突变。回溯使用该段已配置的加速度上限，包括原先只做匀速运动、
实际加速度为零的段。三角形加减速阶段相减产生的舍入级微小平台会在积分前
消除，避免平移时间后出现同一时刻状态不同的情况。

可运行带逐阶段密集采样和连接处连续性检查的数值审计：

```bash
PYTHONPATH=build/install python benchmarks/trajectory_audit.py \
  --seed 20260925 --cases 3000 --samples 2001 \
  --phase-samples 101 --check-continuity
```

加入 `--distribution stress` 可检查不等长路径段、近共线、近反向及更宽的各关节
限位，最高覆盖 32 维；每类几何形状均使用两种剖面。用相同的 `--distribution`、
`--seed` 和 `--case-index` 重放失败。JSON 按失败类型分别保留前十例完整输入，并将构造拒绝与采样
不变量失败分别计数；两者均使命令返回状态码 1。这些检查用于诊断，不构成连续
可行性的数学证明。

C++ 的非零边界速度仍须满足剖面可行性。第一段若必须降低给定起始速度，
构造会直接失败，不会越过起点回溯。两个端点速度都高于标量速度上限、
且空间不足以降到该上限的短凹形剖面也会被拒绝，避免返回错误的末端状态。
